# Problems and resolutions in the mainline attribution round

1. **v61 monitor hash differs from recorded snapshot.** Audited original prefix4923048bytes: exact expected SHA256. Three subsequent JSONL records ended with OWNED_EXITED_DURING_SAMPLE. Retain original prefix hash and final4951845byte hash; no rewriting old evidence.
2. **Startup NUMA gate.** Initial NUMA2 free~31.7GiB and post-v62 NUMA6~24.1GiB were below48GiB. Reused previously approved POSIX_FADV_DONTNEED on179 explicitly recorded project checkpoint/bank files only after owned model exit. Checked inode/mtime/size unchanged. No global cache flush, threshold change or training action. Admission sampled again before new work.
3. **Container-local test namespace.** Absolute host symlink in the scratch test namespace could not resolve inside the read-only /round9 mount. Saved collection failure, replaced it with a relative symlink, reran successfully. Hostcheck containers had no NPU devices; no model HTTP budget was used.
4. **Observer failure semantics.** Fresh review reproduced a start-event failure skipping inference and an end-event error replacing the provider exception. RED regression tests were added; observation now records bounded errors and disables further device timing while preserving exactly one provider invocation and its original result/exception. Reports with observer errors downgrade to incomplete.
5. **Missing trace evidence.** Analyzer originally could label an empty trace as ordinary partial attribution and crash on missing component. RED tests now require spans and coverage; malformed events, dropped spans, missing device timing and observer errors receive explicit incomplete/partial states. Inclusive durations and interval unions are separate; no device overlap is inferred.
6. **Decode evidence.** A one-output request may execute no decode at all. The decode probe now requires at least2 requested output tokens, retains normal EOS, and verifies the captured request identity. Early EOS is recorded as NO_DECODE_EVIDENCE, with no automatic retry.
7. **Capture provenance.** Model/bank matching alone did not enforce the real-row provenance. Tamper regressions now reject a wrong request, missing intrusive-capture declaration, wrong selected row, out-of-range physical rows, and non-NZ actual weight formats. Capture is limited to real row0 of one decode batch; physical padding count is retained. Numerical validation remains the original1% relativeL2 contract, not a post-failure adjustment.

Deferred minor review findings: module discovery is required for all test_mainline_attribution test classes because its direct unittest.main call precedes later classes; an unused hashlib import remains in the HTTP probe. Neither changes executed module-discovery coverage or physical behavior.

8. **Real mapping differs from synthetic qualification fixture.** Actual v63 q32-physical maps and captured gpu_index_to_logical both report contiguous logical0–31. The old Q32 component fixture used0,16,...496. No physical replay was attempted with the wrong map: pre-replay audit detected it. A regression first rejected the real manifest, then the replay-only branch was corrected to load the actual validated resident set; synthetic fixture behavior remains unchanged. The running v63 frozen build was not edited. Replay receives a separate source snapshot, and its receipt identifies the corrected validator/harness. v20 passed with full-model-vs-replay error0 and three equal output hashes.


9. **Cancellation response remains chunk-boundary limited.** The regression passed the cancellation fence and same-process reuse, but control send→CANCEL_SEEN still took339.116509s. This is an observed limitation, not resolved by profiling. No speculative concurrent scheduler or smaller-chunk change was introduced. The expert preparation decomposition is intended to locate the dominant chunk cost before selecting a behavior change.
10. **Remote host interpreter name.** A cleanup command initially used `python`, unavailable on the host; it performed no mutation. It was rerun using `python3`, then exact container identity and stopped state were verified. Container Python remained unchanged.

Post-v63 NUMA file-cache pressure again required the same179-file scoped advice before replay admission; no threshold reduction or active-process cache manipulation occurred. Replay completed on its first physical attempt. Final related tests49/49 passed.
