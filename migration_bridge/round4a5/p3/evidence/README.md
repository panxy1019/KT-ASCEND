# Round 4A P3 Evidence

This directory contains the compact, reviewable artifacts copied from the A3
disposable validation container. Large tensor dumps, the 17.7 GB GGUF, and
full serving logs remain under the frozen A3 artifact root documented in
`../00_P3_EXECUTION_BASELINE.md`.

`SHA256SUMS` is generated after artifact collection and is the byte-level
inventory for the files committed here.
